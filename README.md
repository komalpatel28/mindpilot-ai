# 🚀 MindPilot AI - Next-Gen Interactive Study Hub

**MindPilot AI** is a smart, interactive learning web application designed to help students and learners supercharge their study sessions. By simply pasting study notes, users can instantly convert long-form text into engaging multiple-choice quizzes and flip flashcards to improve active recall and memory retention.

---

## ✨ Key Features

- **⚡ Instant Quiz & Flashcard Generation:** Automatically parses pasted study notes into custom quiz questions and flashcards.
- **🎯 Interactive Quiz Mode:** Test your understanding with multiple-choice questions featuring real-time feedback (green for correct, red for incorrect).
- **🎴 Clickable Flip Flashcards:** Seamless front-and-back flashcard views designed for quick concept review.
- **🌙 Dark / Light Mode Toggle:** Comfortable, high-contrast dark theme and clean light theme for late-night studying.
- **💾 High Score Persistence:** Uses `localStorage` to save and display your personal best quiz score.
- **📱 Fully Responsive Design:** Clean, modern, grid-based UI built to work smoothly across desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack & Technologies Used

- **HTML5:** Semantic document structure and markup.
- **CSS3:** Custom CSS variables, smooth animations, gradient glows, and responsive flexbox/grid layouts.
- **JavaScript (ES6+):** Dynamic DOM manipulation, state management, interactive quiz logic, and local storage integration.
