# Project Scope: MindPilot AI

## Overview
MindPilot AI is an interactive, browser-based study companion designed to transform static study notes into engaging, gamified quizzes with instant performance analytics.

## Core Features
1. **Notes Input & Auto-Save:** Users can paste study notes or type a topic, which automatically saves via local storage.
2. **Interactive Quizzes:** Dynamic question-and-answer flow with immediate visual feedback (correct/wrong highlighting).
3. **Performance Analytics:** End-of-quiz score percentage, correct/incorrect counters, and tailored motivational feedback messages.
4. **Dark/Light Mode:** Seamless theme toggling for comfortable study sessions at any time of day.

## Out of Scope (For this MVP)
- Real-time cloud synchronization of user accounts.
- AI-driven speech synthesis voice customisation (using browser-native fallback options).
