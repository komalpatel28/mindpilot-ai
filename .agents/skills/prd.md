# Product Requirements Document (PRD): MindPilot AI

## 1. Target Audience
- Students, self-learners, and professionals preparing for exams or reviewing dense reading materials.

## 2. User Goals
- Quickly test knowledge retention from raw notes without manual flashcard creation.
- Track accuracy scores and identify areas that need further review.

## 3. Functional Requirements
- **FR1:** The system must allow users to input notes in a resizable text area.
- **FR2:** The system must persist notes locally so refreshing the browser does not erase user data.
- **FR3:** The quiz engine must present multiple-choice questions one by one and evaluate user selections instantly.
- **FR4:** Upon quiz completion, the system must render an analytics dashboard displaying accuracy percentage and score breakdown.
- **FR5:** The UI must support a persistent theme toggle between Light and Dark modes.

## 4. Non-Functional Requirements
- Lightweight and fast client-side performance with zero external heavy framework dependencies (pure HTML, CSS, and Vanilla JavaScript).
- Fully responsive layout adapting seamlessly to mobile and desktop screens.
